# N-CORE

## ----------- / Oque é? / ---------

N-CORE é um chatbot do N de murder drones, ele usa
palavras chaves para te dar respostas, o proposito
deste projeto é o entretenimentoa da pessoa que ira
usa-lo, este projeto será em codigo aberto para caso
de encontrar um bug que não foi resolvido, adicionar
novas palavras chaves ou até criar novas versões 

## --------- / Arquivos / -------

N-CORE.exe
 
LEIA-ME.txt 

N_reboot.py  

N_chat.py 

nfo.json 

## -------- / funções / --------

Sistema falso de reboot

Chat via terminal

Lembrar nome do usuario

## Aviso:
Este programa não realmente instala algo no seu computador
use somente letras minúsculas e não use
pontos de interrogação e exclamação
